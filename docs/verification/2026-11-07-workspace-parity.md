# 工作区 UI 对齐验收

本次依据 Allen 确认的紧凑账号原型及后续反馈，修复应用栏、恢复辅助入口，
增加应用上下拖拽排序。原型中的示例业务状态不作为真实能力移植。

## 逐项对照

| 原型 / 已确认交互 | 本次实现 | 边界 |
| --- | --- | --- |
| 应用栏收起 | 品牌同一行的小侧栏按钮；展开 196、收起 64 逻辑像素 | 窄窗口自动使用图标栏；地区角标区分 CN / GL |
| 上下排列应用 | 展开时悬停显示拖拽柄；收起时长按拖动；⌥↑ / ⌥↓ 键盘调整 | 稳定应用 ID，页面和未完成表单不随显示索引交换 |
| 记住个人布局 | 应用顺序、折叠、常用账号、每页条数、主题和行距本机保存 | 串行写入；失败可见、可重试；不存凭据、余额和领取记录 |
| 总览 | 已载入账号、7 天内到期、待处理；最近 5 个到期账号及应用入口 | 不同平台额度不相加；缺失明细不推断为永久有效 |
| 账号与积分 | 聚合已载入账号，标明平台 / 地区；同一套分页与明细交互 | 同名 ID 按应用隔离；平台 / 身份可搜索；不额外恢复或刷新账号 |
| 应用页头 | 名称、地区、账号数、主操作、恢复和使用说明排列在一行 | 长说明移入帮助；窄窗口自然换行 |
| 紧凑账号表 | 账号 → 余额 → 即将到期 → 最近领取，默认 10 条，支持 5 / 10 / 20 | 正常行高 36，舒适模式 44；十行在 1024×720 一屏可见 |
| 悬停切换 | 账号行悬停或键盘聚焦显示原有切换按钮 | 继续调用平台原有切换流程，不把列表选中当成切换成功 |
| 常用 / 搜索 / 筛选 | 常用状态跨重启保存，默认常用优先；筛选数量；空结果可一键清除 | 不按不可比较的跨平台余额做数值排序 |
| 余额与到期明细 | 余额可点开详情、悬停显示官方查询时间；到期显示最近一批和其他批次数 | 到期已知而余额未知时显示“额度未知”，不显示 0 |
| 最近一次成功领取 | 表格与详情、活动页共用实际 ClaimReceipt | 不从余额倒推发放金额；未确认的领取不会伪装成成功 |
| 模型服务 / Magpie | 左下常驻入口、当前状态与接入说明 | 当前尚无真实模型接口、地址、密钥、模型路由与积分使用顺序 |
| 活动记录 | 各账号最近一次确认领取、当前待处理状态 | 已明确不是完整历史流水；不编造授权、调用日志 |
| 设置 | 系统 / 浅 / 深主题，紧凑 / 舒适行距，精简侧栏，恢复默认顺序 | 不放未实现的开机启动或模型服务开关；自动领取开关仍由账号详情提供 |
| 明暗与窄窗口 | 实际 Flutter 组件 1024×720、480×800 明暗渲染 | 窄窗口表格保留横向滚动；图标悬停可见全称 |

## 数据与副作用

平台账号模块仍是业务事实与调度的唯一 owner。跨平台页面消费现有表格的
只读、内存展示投影，不写账号存储，不调用恢复、查询或领取方法。
UI 偏好使用 Flutter 官方维护的 shared_preferences 异步 API，独立于账号文件。
应用拖拽只影响导航顺序，不影响积分消耗顺序。

已合入 `19632db` 的 ZCode 官方 SDK 验证修改，本轮对平台面板只调整展示。
其他聊天的 beta27 真实账号验收不能代替本包验收；本轮不操作用户账号或真实客户端。
