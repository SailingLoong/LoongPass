# 桌面工作区重设计验收

验收覆盖总览、账号与积分、模型连接、辅助签到、设置，以及从这些页面打开的账号、连接和更新操作。应用沿用 Flutter、Forui 桌面主题、Inter 和思源黑体。原生授权窗口和更新安装器由各自的平台组件提供。

## 运行画面对照

在 1080 × 748 逻辑像素下逐页对照设计稿和加载正式字体的 Flutter 输出。侧栏宽 196，工具栏高 52，标题左沿为 228.4。账号与模型连接抽屉均靠右，宽 462。一级页面主操作采用 Forui 小号按钮，实测高 32，设计稿为 32.3。窄窗及 200% 字号下，标签和操作可换行，账号明细能纵向滚动。

| 场景 | 验证的可观察行为 |
| --- | --- |
| 总览与账号 | 需要操作和等待核验分别计数。点七天日历中的已有批次可进入同一个账号的到期页。国内版与海外版使用独立账号标识。 |
| 额度 | 同一组合成输入分别显示可用余额 860.25 credits、今天到期 160.25 credits 及另一日到期 100 credits。ZCode 的同笔 100 tokens 在两份快照出现时只计一次；另一份独立权益按原数量与单位保留。 |
| 模型连接 | 搜索、排序、开放给 Magpie 和参与 Auto 分别消费模型服务状态。连接侧窗在深浅两种主题都有实色背景，窄窗大字号下仍可打开候选顺序。 |
| 辅助签到 | 浏览总览、账号、回执和详情时仅读取快照。对支持核验的待定回执点击「核验结果」，只读查询一次，提交领取次数为零。批量签到等待两个合成账号的回执及余额刷新完成，再显示最终结果。 |
| 设置与更新 | 切换外观和密度，排序与隐藏平台，保存独立的邀请码。后台下载可显示确定或未知进度，侧栏进入更新详情，准备好后才提供重启操作。 |

账号表格的搜索、筛选、排序与分页由展示 ViewModel 处理。七天日历按本地日期投影额度批次，模型页的 ViewModel 将显式用户操作交给已有服务。浏览页面只读取已有快照。

## 复验

以下命令使用仓库锁定的依赖和对应版本的 Sparkle。

```sh
python3 tool/check.py
LOONGPASS_PREVIEW_DIR=/tmp/loongpass-visual flutter test --no-pub tool/render_desktop_design_test.dart
python3 tool/build_macos_release.py
```

渲染工具使用应用入口与合成的账号、模型和更新数据。它覆盖桌面浅色、深色以及 480 × 800 双倍字号，检查五页导航、窗口边界、两类侧窗、设置四个分组和更新状态。发布工作流在干净的桌面运行器检查原生窗口，并对最终分发包执行签名及源码对应关系校验。本记录的 UI 验收采用模拟账号，真实平台授权、实际领取和客户端切换需要使用各自的业务验收记录。
