# beta 29 集成验收

## 源码与实现

在既有 beta release worktree 集成主线 f78f5a9 和 compact-accounts 921e59f。界面聊天已交接并停止写入，集成、账号验证和发布均由同一执行者负责。仓库本来已公开，沿用 MIT 并补充 LoongPass 和 Sparkle 许可；编译库、安装包和账号数据不入仓。

ZCode 新账号用完可分配设备后自动生成 UUIDv4，授权、结果保存和领取复用同一绑定。旧账号不被自动换号，原未知领取记录保留。已保存账号重新授权仍要求原身份；误选已保存身份不会暗中改绑。设备号有效格式不代表官方活动资格。

自动更新参考 LoongPort e32d3d1d 的 owner、签名校验、安装和重启边界；macOS 使用 Sparkle 2.10.1 官方 SPM 包。原生更新器持有设置与调度，Flutter 只读状态及提交明确操作。应用启动初始化更新器，打开设置页不会触发检查。包及 feed 使用独立发布签名；私钥在仓外和 CI secret 中，未使用 Keychain。
