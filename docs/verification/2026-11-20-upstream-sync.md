## Verification scope

Native RPC and Flutter tests use synthetic receipts and isolated accounts. The tests cover the manual and batch paths, a failed balance read after a confirmed grant, ambiguous network delivery, legacy journals, and explicit rejection. The package lock, analysis, widget and native desktop checks run through `python3 tool/check.py`. Live account grants, real-user challenges and physical Windows and Intel installations require separate acceptance.
