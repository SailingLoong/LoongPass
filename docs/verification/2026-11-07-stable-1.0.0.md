# 1.0.0 正式版验收

日期为 2026-11-07，应用版本为 `1.0.0+31`。

## 发布来源

正式标签 `v1.0.0` 固定源码 `c6eed9c565456d403ed5a051c7131d12ef2aae4c`。[标签 CI](https://github.com/SailingLoong/LoongPass/actions/runs/42346394632) 的 macOS Universal、Windows x64 和发布任务全部成功；同一源码的[主线检查](https://github.com/SailingLoong/LoongPass/actions/runs/42346394701) 也已通过。

[发布附件](https://github.com/SailingLoong/LoongPass/releases/tag/v1.0.0) 提供 macOS 通用 ZIP、Windows x64 每用户安装版与便携 ZIP、SHA-256 及签名更新元数据。下载后核对了源码、全部三份安装包的 SHA-256、Mac 双架构、Windows PE x64 / build 31，以及 Ed25519 更新签名。Windows 分发中没有原生测试程序。

[官网](https://loongpass.com) 已由相同已推送源码经 Wrangler 部署，并显示 1.0.0 双平台下载。下载代理的 Range 请求、四份更新 feed 原字节与静态文件重新验证策略已核对。

## 实机结果

| 检查 | 已观察到的结果 |
| --- | --- |
| Apple Silicon 更新安装 | 通过原生 Sparkle 从 build 30 检查、下载、安装并重启至 `1.0.0 (31)`；保留 12 个账号及原有两个更新开关。 |
| macOS 账号 | ZCode 5 个、WorkBuddy 2 个，MiniMax 两地区、Qoder 两地区及 TRAE 国内版各 1 个恢复；WorkBuddy 官方完整额度查询成功。 |
| Windows 安装 | 在真实 Windows 11 x64 设备重启后安装正式包，安装退出码为 0；已安装主程序及 WinSparkle DLL 的哈希与发布便携包一致。安装位置使用有充足空间的非系统盘。 |
| Windows 存储和协议 | 在该设备运行合成原生检查，覆盖私有权限、单写入者、文档与授权 CAS、未知领取意图、令牌轮换及撤销、PKCE 和 TRAE CNG 格式。合成检查与真实账号证据分别记录。 |
| Windows 已有账号恢复 | 经用户授权复制现有账号，保留领取记录及设备上下文，恢复同样的 12 个账号。WorkBuddy 两个账号取得真实身份核对结果；通过账号详情按钮查询官方完整额度，当前余额、最近到期剩余额度及未知到期部分与 macOS 查询一致，并核对了本次查询时间。手工解压文件须保持当前用户所有权，不能用 Administrators 作为所有者；本次修正测试导入文件所有权时逐一确认内容未变，未放宽应用检查。 |
| Windows 更新设置 | 从实际界面分别开启、关闭“自动检查并下载更新”及“接收 Beta 版更新”；每步核对界面状态与原生设置一致，两个选项互不联动，最后恢复为初始关闭。正常退出后重开，12 个账号及两个开关状态保留。 |
| Windows 手动检查 | 从应用内“检查更新”打开原生 WinSparkle，实际返回 `LoongPass 1.0.0 is currently the newest version available.`。此项证明原生检查和 feed 连通，不代表已执行 Windows 更新安装。 |

真实账号、身份标识、凭据、设备信息及完整回执只保存在私有验收材料中。测试前后 10 份账号、安装身份和领取日志文件逐项比对一致。macOS 与 Windows 没有同时运行同一批账号的自动任务。

## 验收边界

- Windows 本次使用已有授权的受控副本，尚未完成各平台全新官方授权、验证码及新奖励到账。没有为验收重复领取奖励。Windows 更新下载、验签与安装仍需下一次更高版本的真实升级补齐。
- Windows 界面操作使用交互式用户会话中的 MSAA 控件与原生设置回读；另经 UU 远程实际观察，重启后的 12 账号列表、`1.0.0 (31)` 版本及两个更新开关显示正常。SSH 的 GDI / PrintWindow 白图未作为应用绘制失败的依据，未修改渲染器或系统图形设置。
- Mac 包已核对 Universal，实际硬件覆盖 Apple Silicon；Intel 真机尚未验收。Developer ID 签名、公证及 Windows Authenticode 尚未配置，更新 Ed25519 签名不替代系统代码签名。
- WorkBuddy 客户端切换、Magpie 模型服务、LobsterAI 与 Loomy 当前仅在 macOS 开放。新增奖励渠道的真实授权与到账仍按各自模块记录验收，不能以包含于正式包代替。
