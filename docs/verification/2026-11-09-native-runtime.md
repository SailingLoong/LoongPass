# Magpie 原生运行层：beta 33 验收

本记录覆盖 `1.0.1-beta.33+33` 的源码、合成检查和 Apple Silicon 真实接入。安装包来源与提交由发布附件 `SOURCE_COMMIT` 和标签 `v1.0.1-beta.33` 确定；构建通过不能代替 Windows / Intel 真机验收。

## 结构与固定来源

LoongPass 直接运行 Magpie 原生 Bun 插件宿主和完整供应方插件包。原生 `plugin-auth` 独占授权保存与续期；LoongPass 管理私有目录、账号事实、领取事务、任务调度和既有客户端激活。外部 Magpie 通过原生 LoongPass 插件取得每账号目录，负责模型分组、选路、客户端协议转换及原生推理恢复。已移除旧 Dart 供应方翻译、内部模型路由和重复凭据 owner。

来源唯一 owner 是 `runtime/upstream.lock.json`。44 份上游文件及六个完整包分别校验有效内容；按顺序反向应用已审查补丁，必须恢复固定上游原始哈希。Git 换行偏好和 Windows 默认文本编码不影响校验。必要原生差异、回归和移除条件见 `runtime/README.md`；不会在启动时追踪 latest。

## 合成检查与回归

仓库检查运行真实固定插件代码，厂商接口使用隔离合成响应。覆盖授权/续期与损坏存储恢复、身份和地区隔离、迁移中断与唯一写入者、独立账号目录、取消和大流背压、工具及默认客户端请求、精确额度、领取未知状态和原生桥接。

关键修复包括 Qoder 代码示例误触发工具、Loomy 同掩码身份冲突、未知额度被归零、供应方精度及到期字段、WorkBuddy 桌面恢复的身份绑定，以及 ZCode 设备/个人与团队身份下的同一活动领取事务。其他每日奖励也按官方身份持久化，删除后重新授权不重置未知领取或回执。

真实外层 Go 网关验收又捕获一个宿主单测没有发现的问题：Magpie 传入的是原生 API 模型 ID。桥接现保留该 ID、SDK 和 URL，并在所选账号自己的目录内核验；不能借此访问其他账号或协议。回归使用互不相同的目录 ID 与 wire ID，覆盖两个真实宿主之间的请求。

额度检查核对绝对值与单位。例如合成窗口 `99,999.125 credits` 已用，加 `0.875 credits` 剩余，等于 `100,000 credits` 总额；列表和详情都保留小数。重叠窗口独立展示，不重复合计。领取日期已知而具体时刻未知时保留日期，不伪造精确到账时间。

## Apple Silicon 真实接入

使用安装版 Magpie `0.1.3302`、DeepSeek Harness `0.2.2-rc.1` 和 Claude Code `2.1.311`，经过实际外层 Magpie → 原生 LoongPass 插件 → 本机服务 → 原生供应方插件。没有替换默认 system 或删去默认工具来绕过失败。

| 实际路径 | 观察结果 |
| --- | --- |
| WorkBuddy 两账号 | 每个账号固定独立 grant，工具请求计算 `19 + 23`，回传 `42` 并取得精确最终标记 |
| MiniMax 国内、国际各一账号 | 同样完成实际工具往返 |
| Qoder 国内一账号 | 同样完成实际工具往返 |
| ZCode 四个已启用账号 | 显式 Trial 模型完成实际工具往返；该验证未购买或充值 |
| Harness headless | 通过官方 `magpie dsh` 配置，默认环境实际执行 `python3 -c "print(19+23)"`；工具结果 42、最终精确标记、退出码 0 |
| Harness 桌面标准模式 | 新会话显示 DeepSeek-V4.1-Flash · LoongPass；实际终端命令完成并输出 42，最终返回 `DESKTOP_NATIVE_42`，没有原来的 HTTP 400 |
| Claude Code 正常环境 | 通过官方 `magpie claude run`，实际 Bash 工具输出 42，最终精确标记，成功退出 |

以上覆盖当前启用的九个本地账号 grant，不代表所有平台、所有模型均已真机调用。Loomy、TRAE 和未启用的 Qoder 国际推理只覆盖本轮源码/合成契约；历史真实测试不能替代本次新链路验证。

## 账号、迁移与真实客户端切换

迁移前已保存并校验原始私有备份。实际恢复 13 个已保存账号，保留地区、自动设置、设备及领取历史；关闭再启动后仍从原生授权库恢复。旧凭据 owner 在原生导入前退休，重入不覆盖已经旋转的新授权。原始备份继续保留观察，未提交账号文件或真实响应。

WorkBuddy 激活从当前 native grant 重新读取完整官方 profile，再走已有 Swift 原子事务。候选完成 A → B → A 的官方客户端切换，两次均从官方 UI 复制 UID，与所选账号一致；临时核对草稿已清空，没有发送身份文本。一次切回准备因退出尚未完全确认返回 busy，等待客户端正常退出后重试成功，没有强制绕过写入者检查。

Codex 官方账号管理保持独立；本轮未重新执行 Codex 真机切换。其他供应方客户端切换也不由账号选择或模型调用成功推导。未为了验收重复领取奖励，真实到账、所有渠道全新登录与轮换、Windows / Intel 真实账号运行仍分别按实际资格和设备记录。

ZCode 普通 freeFirst 模型允许赠送后使用已有套餐，显式 `-Trial` 仅赠送；名称、内部身份和额度来源分别保留。推理采用用户已接受的 Magpie 原生恢复，可能额外消耗额度；未知签到仍禁止盲目重发。LobsterAI 保持停用。
