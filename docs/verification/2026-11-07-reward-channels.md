# LobsterAI 与 Loomy 接入检查

本记录覆盖新增源码，不代表 beta 30 安装包已经包含这些功能，也不代表真实账号已授权或奖励已到账。

## 已实现的源码行为

- LobsterAI：查询官方客户端版本、打开官方浏览器授权并接收本机回调；校验回调状态、路径、方法及 Host。使用官方稳定账号 ID，保存授权和刷新材料，复用已取得的结果，避免保存重试时重复交换一次性授权。
- Loomy：用户明确请求短信后完成官方会话登录，保存官方 `userid`；同一授权在官方拒绝之前继续复用，不把请求中希望的会话时长当作官方过期时间。每日赠送池初始化与永久积分分开，日池消耗后不重复补充，新增发放差值无法核实时保留未知。
- 共用账号 owner：私有原子文件、单写入者与 CAS；按平台和官方身份隔离账号，刷新授权先保存。应用启动和定时任务负责查询/领取，打开页面、搜索和查看明细不触发网络。
- 领取前保存意图；断线、超时、5xx、解析失败等不确定结果不重发，重启、重新授权、删除后重新添加均保留该保护。官方明确未执行的拒绝另存为可安全重试的拒绝，重新授权后可在当天重试。
- 新平台元数据只在协议注册处登记，导航与页面从注册清单派生；保留旧平台 ID、顺序与用户偏好。详情使用现有账号表格的实时快照。
- Xcode 在签名前把根目录许可、来源声明及 Rust 许可复制进应用的 `Contents/Resources/Legal`。源码文件仍为唯一来源，新增同类许可不需要另改文件名单。
