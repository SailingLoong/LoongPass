# Forui 桌面界面验收

## 实现与工具链

桌面自研界面采用 Forui 0.27.7 的官方 Neutral Desktop 浅色、深色主题，直接使用其按钮、表单、选择器、开关、卡片、提示、对话框与设计变量。主题由应用根节点统一提供。账号表格保留原有搜索、筛选、排序、分页、收藏和行距行为，读取同一套主题。

Flutter 固定为 3.47.9，Dart 约束为 `>=3.13.7 <4.0.0`。本次本机构建使用 Flutter 3.47.9 stable 与配套 Dart 3.13.7。`material_ui` 提供 Forui 官方桥接所需的应用宿主及可选中文本基础能力。原生插件、运行时及桥接的来源与版本继续由 `runtime/upstream.lock.json` 和第三方声明记录。

## 自动检查与构建

- `python3 tool/check.py` 完整通过，包含 Dart 静态分析、252 项 Flutter 测试、286 项原生插件测试，以及存储、迁移、授权、领取事务和 Codex 原生检查。
- 回归覆盖主题切换、中文本地化、重复标签的选择项、进行中及禁用状态、收藏状态、到期提示颜色、悬停与键盘焦点、2 倍文字及窄窗口。
- `tool/render_compact_accounts_test.dart` 的 6 组检查通过，生成 44 张合成数据预览，覆盖 480、800、1024 宽度及浅色、深色、折叠导航和弹窗。测试渲染器使用 macOS 中文字体替换测试字体，原生应用的 Inter 与系统中文回退另经运行界面检查。
- `python3 tool/build_macos_release.py` 完成 macOS Release 构建，应用及 Flutter 框架均含 arm64 与 x86_64。严格代码签名检查通过。

两次独立运行曾在既有 Codex 合成关闭用例中遇到 `Closing handshake missing`，完整检查随后复跑通过。该用例及对应原生实现相对本次合入基线没有修改，失败原因仍待单独定位。
