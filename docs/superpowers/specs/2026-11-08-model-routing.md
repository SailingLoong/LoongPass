# 按模型跨平台路由

Allen 确认：Magpie 选择 LoongPass 的某个模型，LoongPass 从提供该模型的全部已连接平台与账号中选路；同一 session 优先黏在同一账号以保留缓存机会。优先验证 Qwen、HY、DeepSeek、GLM 与 Kimi，具体版本由账号的官方目录决定。

## 边界与决定

- 模型服务拥有统一目录、调用授权、选路和会话亲和性；平台账号 owner 继续独占身份、授权刷新与额度事实。目录来自已有适配器，页面和 HTTP 读取不触发刷新或领取。
- 推荐沿用现有 `ModelProvider` 与官方动态目录，在模型服务收敛选路。另建平台白名单会复制来源事实；把账号选择继续放在 Magpie 无法实现这里要求的跨平台会话亲和性，均不选。
- 同一明确模型 ID 仅归一大小写与分隔形式；版本、日期和变体保留。Auto、Fast 等未能证明底层模型的档位保留来源命名空间，不跨平台合并。缺少某版本就报告缺口，不用旧模型冒名。
- 新统一入口提供 Anthropic Messages，Magpie 继续转换各类客户端协议。服务选路后集中衔接平台原生 Chat 或 Messages；原平台账号入口继续保持其原有授权范围。
- 统一入口使用独立、本机持久化调用密钥，旧账号 key 不获得跨账号权限。只有明确加入模型服务且启用的账号进入路由池，撤销或账号生命周期变化立即生效。
- 同一调用者、模型和 session 优先复用仍可用的账号。新会话分散到可用账号；未提供 session 时不把无关请求黏为一个会话。亲和性记录有容量和闲置期限，不保存对话。
- Magpie 使用原生 header 模板传递 session；保留模型请求中的系统提示词、工具与历史。平台调用失败或结果未知的请求不自动重发；后续请求可换到同模型的其他可用账号，换路后优先留在新账号。
- 纯图片生成模型不进入对话目录；跨协议无法表达的输入明确拒绝，不静默丢失内容。
- 代码、合成协议测试、真实平台调用、Magpie/Claude Code 整链、安装包发行分别验收。未发现 K3.1 的当前账号不得宣称已打通该版本。LobsterAI 保持停止接入。

## 验收

统一目录中同模型去重且列出来源；真实跨平台模型覆盖至少两平台。合成验证会话复用、并发会话、故障后下一请求换路、撤销、旧 key 权限、重启恢复与流式/工具协议转换；真实客户端逐模型验证文本、流式和工具往返，并核对请求实际到达的账号与官方额度单位。
