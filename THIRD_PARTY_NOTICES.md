WebView2 documentation is available from https://learn.microsoft.com/microsoft-edge/webview2/.

## Native Magpie plugin runtime

The application includes complete Magpie community plugin packages and the Magpie
Bun host at the fixed repositories, commits and package versions recorded in
`runtime/upstream.lock.json`. Original and effective SHA-256 hashes, together
with reversible source patches, retain exact upstream provenance. See
`runtime/README.md` for the local changes and their removal conditions.

Magpie's MIT license is retained in `runtime/vendor/magpie/LICENSE`; each community
package retains its license and any component-specific notices in its directory.
Qoder retains the CLIProxyAPI MIT notice. Earlier derived-component notices remain
in this repository for the historical implementation; its duplicate Dart model
request/response translators have been removed.

Bun is obtained from its official release at the locked version and verified
before use. Runtime executables are not tracked as binaries in this repository.
